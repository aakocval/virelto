# Virelto Tools

A privacy-first, client-side PDF toolkit, served from
[vireltotools.com](https://vireltotools.com). Every PDF operation — merge,
split, rotate, delete/reorder pages, sign, images↔PDF — runs entirely in
the browser using `pdf-lib` and `pdf.js` inside a Web Worker. Files are
never uploaded. The server exists only for authentication and billing.

See [docs/development.md](docs/development.md) for architecture, setup, and
deployment notes.
